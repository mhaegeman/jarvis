# UI/UX Pro Max

## Overview

Design intelligence for pro UI/UX decisions across web/mobile. Covers design styles, palettes, typography, accessibility, UX patterns, data viz across stacks.

Source: [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

## When to Use

- New UI component or screen
- Select/generate design system, palette, font pairing
- UX decisions (layout, interaction, accessibility, data viz)
- Stack-specific UI guidelines (React, React Native, Vue, etc.)
- **Not for:** backend logic, data modeling, API design

## Core Workflow

1. **Analyze requirements** — Extract: product type, audience, style keywords, tech stack
2. **Generate design system** — Styles, colors, fonts, UX patterns
3. **Supplement w/ domain searches** — Drill into accessibility, charts, typography
4. **Apply stack guidelines** — Stack-specific practices

## Priority Order

1. **Accessibility** — WCAG contrast, keyboard nav, ARIA labels
2. **Touch & Interaction** — 44×44px min tap targets, feedback timing
3. **Performance** — image optimization, layout stability, lazy loading
4. **Style Consistency** — match product type/brand, no emoji icons in UI
5. **Responsive Layout** — mobile-first, systematic breakpoints

## Quick Reference

| Need | Approach |
|------|----------|
| New project design system | Analyze requirements → full system generation |
| Color palette | Match product type + audience + mood |
| Typography | Font pairing aligned to style and readability |
| Accessibility audit | Check contrast, tap targets, ARIA labels, keyboard nav |
| Chart / data viz | Match chart type to data relationship and audience |
| Component library | Align to existing design tokens and stack conventions |

## Pre-Delivery Checklist

- [ ] Visual quality verified at multiple screen sizes
- [ ] Interaction patterns validated (hover, focus, active states)
- [ ] Theme compliance confirmed (colors, spacing, typography)
- [ ] Layout robustness tested across breakpoints
- [ ] Accessibility conformance checked (contrast, ARIA, keyboard)
