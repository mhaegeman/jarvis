# UI/UX Pro Max

## Overview

Design intelligence system for professional UI/UX decisions across web and mobile. Covers design styles, color palettes, typography, accessibility, UX patterns, and data visualization across multiple technology stacks.

Source: [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

## When to Use

- Starting a new UI component or screen
- Selecting or generating a design system, color palette, or font pairing
- Making UX decisions (layout, interaction, accessibility, data viz)
- Implementing stack-specific UI guidelines (React, React Native, Vue, etc.)
- **Not for:** backend logic, data modeling, API design

## Core Workflow

1. **Analyze requirements** — Extract: product type, target audience, style keywords, technology stack
2. **Generate design system** — Produce comprehensive recommendations (styles, colors, fonts, UX patterns)
3. **Supplement with domain searches** — Drill into specific areas: accessibility, charts, typography
4. **Apply stack guidelines** — Implement with stack-specific practices

## Priority Order

Always prioritize in this order:

1. **Accessibility** — WCAG contrast ratios, keyboard navigation, ARIA labels
2. **Touch & Interaction** — 44×44px minimum tap targets, appropriate feedback timing
3. **Performance** — image optimization, layout stability, lazy loading
4. **Style Consistency** — match product type and brand, avoid emoji icons in UI
5. **Responsive Layout** — mobile-first design, systematic breakpoints

## Quick Reference

| Need | Approach |
|------|----------|
| New project design system | Analyze requirements → full system generation |
| Color palette | Match product type + audience + mood |
| Typography | Font pairing aligned to style and readability |
| Accessibility audit | Check contrast, tap targets, ARIA labels, keyboard nav |
| Chart / data viz | Match chart type to data relationship and audience |
| Component library | Align to existing design tokens and stack conventions |

## Pre-Delivery Checklist

- [ ] Visual quality verified at multiple screen sizes
- [ ] Interaction patterns validated (hover, focus, active states)
- [ ] Theme compliance confirmed (colors, spacing, typography)
- [ ] Layout robustness tested across breakpoints
- [ ] Accessibility conformance checked (contrast, ARIA, keyboard)
