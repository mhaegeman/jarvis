Jarvis · Visual Prototypes

Four directions for the Jarvis UI. Click any card to open the live prototype. Each prototype has buttons to demo the idle / think / speak states.

A · Living Orb

The core that breathes

A central, deforming sphere of light. Pulses while idle, swells and shifts to warm hues when speaking. Iconic, focused, calm.
B · Waveform

The presence that flows

Layered audio-reactive waveforms across the full screen. Minimal, ambient, atmospheric. Text floats above the motion.
C · Holographic HUD

The cockpit

Multi-panel sci-fi command surface. Live telemetry, calendar, status indicators. Conversation in the centre. Information-dense.
D · Liquid Typography

The voice that writes itself

Text is the entire stage. Letters drift in, distort, dissolve, reform. Editorial, restrained, unmistakably human-scale.
Open any one full-screen by clicking. To preview locally, run python3 -m http.server from prototypes/ and visit http://localhost:8000.
