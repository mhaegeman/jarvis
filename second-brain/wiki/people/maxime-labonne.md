## Overview

Maxime Labonne is a machine learning researcher and educator, best known as the author of the widely-referenced free LLM Course on GitHub and co-author of the "LLM Engineer's Handbook" (Packt, 2024). He is active on X (@maximelabonne) and Hugging Face (@mlabonne). His work focuses on making LLM engineering accessible through practical, runnable notebooks.

## Key Facts

- Creator of the `mlabonne/llm-course` GitHub repo — one of the most-starred LLM learning resources.
- Co-authored "LLM Engineer's Handbook" (Packt, 2024) — an end-to-end LLM application guide.
- Notable tools/contributions: LazyMergekit, LazyAxolotl, AutoQuant, AutoAbliteration, AutoDedup, LLM AutoEval.
- Covers fine-tuning (SFT, DPO, ORPO, QLoRA), quantisation (GPTQ, GGUF, EXL2, AWQ), model merging (MergeKit), and MoE creation.
